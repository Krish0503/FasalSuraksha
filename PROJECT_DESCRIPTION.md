## 🚀 Detailed Description (200 words)

**FasalSuraksha** (meaning "Crop Protection" in Hindi) is an innovative AI-powered web application designed to revolutionize agricultural disease management. Built by the Nirvana Coders team, this platform combines state-of-the-art machine learning with user-friendly design to make crop protection accessible to farmers worldwide.

**Core Features:**
- **Instant Disease Detection**: Upload a plant leaf image and receive accurate disease identification within seconds using our TensorFlow CNN model trained on 39 disease categories across 14 crop types
- **AI Agricultural Expert**: 24/7 access to Google Gemini-powered chatbot providing personalized farming advice, treatment recommendations, and pest control strategies
- **Comprehensive Treatment Guide**: Detailed information on disease causes, symptoms, and organic/chemical treatment options
- **Secure Authentication**: Multi-method login via Google OAuth and email/password through Firebase
- **User Engagement**: Built-in feedback system and contact forms to continuously improve the platform

**Technical Excellence:**
Built with Flask, TensorFlow 2.15, and Google Gemini AI, FasalSuraksha demonstrates the power of modern web technologies in solving real-world agricultural challenges. The responsive design ensures accessibility across all devices, from smartphones in the field to desktop computers at home.

**Impact:**
By democratizing access to AI-powered agricultural expertise, FasalSuraksha helps farmers make informed decisions, reduce crop losses, and improve yields—contributing to food security and sustainable farming practices.

## 🎓 Academic/Technical Description (150 words)

**FasalSuraksha** is a full-stack web application implementing deep learning for agricultural disease detection. The system employs a Convolutional Neural Network (CNN) trained on plant pathology datasets, achieving multi-class classification across 39 disease categories with high accuracy.

**Architecture:**
- **Frontend**: Responsive HTML5/CSS3/JavaScript interface with Bootstrap framework
- **Backend**: Flask 3.0 RESTful API with session-based authentication
- **ML Pipeline**: TensorFlow 2.15 CNN model with 160x160 input preprocessing
- **AI Integration**: Google Gemini 2.5-flash for natural language processing
- **Authentication**: Firebase Admin SDK with JWT token verification
- **Database**: Firebase Firestore for user data and feedback storage

**Key Technologies:**
Python 3.12, TensorFlow, Flask, Firebase, Google Gemini AI, Bootstrap 5

**Innovation:**
Combines computer vision for disease detection with conversational AI for agricultural consultation, providing a comprehensive digital farming assistant accessible via web browsers on any device.
