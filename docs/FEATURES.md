## 🚀 Quick Start

1. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```

2. Get Gemini API key from: https://makersuite.google.com/app/apikey

3. Create `.env` file:
   ```
   GEMINI_API_KEY=your_key_here
   ```

4. Run the app:
   ```bash
   python app.py
   ```

5. Open: http://localhost:5000

## 💡 Usage Tips
